# Work-package venture planning

Ventures plan along four **work packages** (align folder skeleton and living TEMPLATEs):

| Work package | Folder / doc | Purpose |
|--------------|--------------|---------|
| **Capacity** | Capacity / Building Capacity | Skills, tools, space, relationships needed to deliver |
| **Deliverables** | Deliverables / R&D | Products, services, research outputs |
| **Dissemination** | Dissemination / pipeline | Outreach, publishing, market/commons interface |
| **Process** | Process / methodology | How the venture works day to day |
