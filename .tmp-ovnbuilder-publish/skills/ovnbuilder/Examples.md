# Examples

## 1. Bootstrap a new reference OVN

User: “We want an open value network for open hardware sensing.”  
Route: Orient → AssessReadiness → BootstrapNetwork.  
Emit: glossary, Fourth Sector placement (contrast private/public/solidarity when useful), 6C scorecard, roles skeleton, feature map, HumanEscalation if culture/legal gates fire. Cite Knowledge. Point to HelpHumans.

## 2. Create a product venture

User: “Create a venture for a open-source device.”  
Route: CreateVenture → KickstartVenture.  
Emit: venture type, openness mode, work-package matrix, folder skeleton, Catalog TEMPLATEs to remix, join-form link notes.

## 3. Diagnose an existing network

User: “Is our coop actually an OVN?”  
Route: DiagnoseOvnness.  
Emit: evaluation profile; sector placement (solidarity vs fourth); capture risks; HumanEscalation for ambiguous capture trajectory. Do not default-subsume open networks under social-economy legal forms.

## 4. Collaborative entrepreneurship

User: “Help us pick a business model that fits p2p.”  
Route: CollaborativeEntrepreneurship modes A (Enterprise Stack) and/or B (patterns).  
Emit: stack map with OVN checks; ranked patterns with adaptation rules; Fourth Sector / collaborative-entrepreneur framing; capital-governance human gate.
