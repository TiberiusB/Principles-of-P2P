# EvaluationFramework (condensed)

Embedded bridge from Principles-of-P2P evaluation practice. Full rubrics live in Knowledge excerpts where available. Offline-capable.

## Profile-first diagnosis

Evaluate the network as a **profile**, not a single score:

1. **Openness & permissionlessness** — who can join/contribute?
2. **Transparency / holoptism** — traces visible horizontally and vertically?
3. **Contribution accounting** — log exists? portable across ventures?
4. **Benefit redistribution** — multi-dimension? capture-resistant?
5. **Commons / custodianship** — shared layer protected? custodian ≠ extractor?
6. **Governance distribution** — decision rights vs capital plutocracy?
7. **Infrastructure reciprocity** — who pays for shared rails?
8. **Stigmergy vs opaque command** — can affiliates self-select into work?
9. **Exchange interface** — market access without swallowing the commons?
10. **Capture / enclosure trajectory** — stress test: sponsor, platform, IP, brand?

## Stress tests (sample)

- If the largest funder leaves, does contribution accounting still hold?
- If the exchange firm pivots, do affiliates retain commons access?
- If a platform ToS changes, can the network export its traces?

## Scoring

Use qualitative bands (strong / mixed / weak / absent) plus evidence citations. Mark UNVERIFIED when evidence missing. Human gate: ambiguous OVNness → experienced assessor (`HelpHumans.md`).

## Ethos / Truth-Value cross-check (SHOULD)

When diagnosing, briefly note ethos alignment and whether value claims match observable contribution/benefit traces.

## Sector placement (SHOULD)

Locate the subject on **private / public / solidarity (3rd) / fourth** using property regime, governance, and organizational architecture (`FourthSector.md`, `ovn.fourth_sector`). OVN-like practice is expected in the **Fourth Sector** (nondominium, contribution-linked benefits, stigmergy / peer governance, collaborative entrepreneurship). Flag trajectories that capture the network into another sector’s box (e.g. private enclosure, solidarity legal-form subsumption, public dependency as identity) without denying legitimate **interfaces** (grants, exchange firms).
