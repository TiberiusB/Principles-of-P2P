# Tool selection

1. List required **features** (`InfrastructureFeatures.md`).
2. Check OVN principles fit (transparency, exportability, low capture).
3. Only then name **example** tools, with class caveats:

| Class | Typical strengths | Caveats |
|-------|-------------------|---------|
| Web2 suites | Fast start, familiarity | Centralization, export lock, ToS capture |
| Federated messaging | Autonomy | Fragmentation, ops load |
| Blockchain / DAO | Public ledgers | Cost, plutocracy risks, complexity |
| Holochain / hREA / Nondominium-class | Agent-centric, Valueflows affinity | Maturity, learning curve |
| Hybrid | Pragmatism | Capture at junction points |

Never present a single NRP/CAS product as mandatory.
