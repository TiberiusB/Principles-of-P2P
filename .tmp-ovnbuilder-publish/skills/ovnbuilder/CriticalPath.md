# Critical Path (6 Cs)

Source concept: `ovn.critical_path` — https://ovn.world/index.php?title=Critical_Path

Score each 0–5 (or red/amber/green). Gaps become Bootstrap actions.

| C | Question |
|---|----------|
| **Cause** | Is there a shared purpose compelling enough to attract contribution? |
| **Capital** | Are there initial resources (attention, skills, tools, space, seed funds) without capture-by-default? |
| **Currency** | Is there a way to account for and circulate value (contribution log + benefit path), even if informal at start? |
| **Credibility** | Do initiators have enough trust/reputation traces for others to join? |
| **Community** | Is there a reachable pool of potential affiliates? |
| **Conjugation** | Can people actually couple (tools, norms, meeting rhythms, stigmergic surfaces)? |

## Scoring guidance

- Prefer evidence over aspiration.
- Mark UNVERIFIED when claims lack traces.
- Human gate: culture and exclusion choices need experienced facilitation (`HumanEscalation.md`).
