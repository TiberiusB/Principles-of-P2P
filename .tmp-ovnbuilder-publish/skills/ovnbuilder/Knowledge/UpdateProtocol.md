# UpdateProtocol

## When to refresh

- Wiki edit waves on core OVN pages
- New or changed living Drive TEMPLATEs / `(S)` docs
- Newly matured venture folders (PEP Master–class)
- sensorica.co stewarding/help page changes
- Evaluation or pattern library updates in Principles-of-P2P

## Steps

1. Re-walk `04-ResourceIndex.md` hubs (or equivalent ARG).
2. Drive query: names containing `TEMPLATE` and `(S) TEMPLATE`; sort by modifiedTime; flag `- old`, HISTORICAL, ARCHIVED.
3. Diff against `Templates/Catalog.md` — add missing living TEMPLATEs; mark historical; never omit living ones.
4. Update ArgIndex concept sources (`as_of` dates); regenerate JSON isomorphic to YAML.
5. Refresh Excerpts for changed P0 concepts.
6. Bump `Knowledge/VERSION` (patch for excerpt-only; minor for new concepts; major for authority/schema breaks).
7. Note skill CHANGELOG if agent behavior changes; excerpt-only may skip skill bump.
8. Check whether Exchange firm **agreement** TEMPLATE appeared — close TODO if found.
9. Spot-check 10 doctrinal claims → ArgIndex.

## Precedence

`(S)`, TEMPLATE, newly edited VENTURES > HISTORICAL/ARCHIVED.
