# Governance levels

| Level | Concerns |
|-------|----------|
| Network of networks | Interoperability, federation norms, shared protocols |
| Network | Brand, custodian mandates, infrastructure reciprocity pattern, affiliate norms |
| Venture | Goals, openness mode, contribution/benefit policy, work packages |
| Local | Lab/site rules, physical access, local liability |

Custodian and exchange firm mandates sit primarily at network and venture interfaces. See Templates Catalog for living TEMPLATEs.
