# Orient — Heliograph Collective

An OVN is an open organizational framework for peer production with contribution-related benefits (`ovn.definition`).

Intended placement: **Fourth Sector** practice (p2p economy, nondominium-class property, collaborative entrepreneurship) — orthogonal to private, public, and solidarity sectors (`ovn.fourth_sector`).

Roles: Affiliates; Custodian ≠ Exchange firm; Ventures as work contexts.

Sensorica is precursor + help destination — not required brand (`ovn.sensorica_precursor`, `help.ovn_support`).

Citations: Knowledge/ArgIndex ovn.definition, ovn.economic_model, ovn.fourth_sector.
