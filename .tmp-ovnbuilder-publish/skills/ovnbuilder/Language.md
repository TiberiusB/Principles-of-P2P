# Language (glossary)

| Term | Meaning |
|------|---------|
| OVN | Open Value Network — open organizational framework for peer production with contribution-related benefits |
| Affiliate | Person participating in the network without implying employment |
| Agent | Acting participant (human or, where declared, automated) contributing to ventures |
| Venture | For-benefit open enterprise / work context under network governance |
| Project | Often narrower/task-scoped; prefer Venture for OVN economic unit |
| Custodian | Holds property/trust/liability/transaction/referee functions for commons assets |
| Exchange firm | Market-facing entity; must not silently absorb custodian powers |
| NRP | Network Resource Planning — process/resource planning capability class |
| CAS | Contribution Accounting System — log + evaluate contributions |
| Contribution | Logged input of work, resources, or care toward a venture/network |
| Benefit redistribution | Policy/algorithm allocating benefits across dimensions (revenue, governance, reputation, access) |
| Contribution-derived participation | Claims/voice tied to contributions (preferred wording; avoid “fluid equity” as doctrine) |
| Stigmergy | Coordination via traces in a shared environment rather than only command chains |
| Commons | Shared resources governed for continued access and non-capture |
| Nondominium | Property framing where no party dominates exclusive ownership of the shared layer |
| Pool of shareables | Shared pool of resources available under network rules |
| Network of networks | Federated OVNs / nested governance |
| Holoptism | Horizontal and vertical transparency of activity and context |
| Work package | Planning axis: Capacity, Deliverables, Dissemination, Process |
| Fourth sector | Orthogonal socioeconomic sector for p2p / open / collaborative practice (nondominium, collaborative entrepreneurs, stigmergic governance); not a residual after private / public / solidarity |
| Private sector | Market-oriented sector; dominant private property and market value; agents typically called entrepreneurs |
| Public sector | State-oriented sector; dominant public property and public value; agents typically bureaucrats / public managers |
| Solidarity sector | Also 3rd / social sector; shared property or commons (often state-protected); social value; agents typically social entrepreneurs — do not default-subsume OVNs here |
| Collaborative entrepreneur | Fourth-sector initiator who builds multi-value incentive webs for open contribution (not the same as private-sector entrepreneur or solidarity social entrepreneur) |
