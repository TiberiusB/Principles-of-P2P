# Infrastructure feature families

Do **not** mandate vendors. Map needs to features, then pick examples with caveats (`ToolSelection.md`).

| Family | Capability |
|--------|------------|
| Identity / profile | Who is participating; portable reputation hooks |
| Communication | Sync/async messaging |
| Coordination / signaling | Calls for contribution, workparties, alerts |
| Collaboration | Co-editing, design, code, hardware docs |
| Contributions log | Persistent contribution records |
| Evaluation | Peer/process evaluation of contributions |
| Benefit redistribution | Policy execution / transparency of allocation |
| Exchange | Market interface (often via exchange firm) |
| Process / resource planning (NRP-class) | Plans, inventories, flows — optional product |
| Knowledge / discovery / sensemaking | Wiki, search, maps |
| Reputation / roles / feedback | Soft power without capture |
| Governance / decision / norms | Proposals, consent, brand rules |
| Legal interface surfaces | Agreements, custody records |
| Physical collab spaces | Labs, meetups |
| Search | Find people, docs, open tasks |
| Responsibility transfer | Handoffs without orphaning assets |

Principles for the digital environment: transparency, openness, horizontal/vertical visibility and mobility, collaboration/social intelligence, stigmergy.
