# Business Models Consulting Methodology

This folder contains a reusable methodology for opportunity-oriented consulting based on the Principles-of-P2P assessment framework. It distills the process used for Flowsta and YourOwnAI into materials that an AI agent can follow with human supervision.

The methodology starts with evidence-grounded P2P assessment, then adds a consulting layer: current economic model diagnosis, technical capability mapping, new value-layer discovery, sustainability design, and a founder-friendly migration path.

## When to use

Use this methodology when analyzing an organization, project, open-source tool, hApp, network, cooperative, or hybrid venture and the goal is to help its stewards see better economic and organizational opportunities.

It is especially useful when:

- the organization has strong values but an incomplete economic model;
- the technology points toward commons, peer-to-peer, or open-network potential;
- current monetization risks enclosing the very value the organization wants to create;
- a founder or steward needs practical, non-dogmatic guidance;
- an AI agent needs a repeatable consulting workflow grounded in this repository.

## Relationship to P2P-ness assessment

The existing assessment workflow in `templates/template_prompt.md` remains the evidence base. It produces data, scores, compilation, and executive summary files.

This consulting methodology adds a second layer:

1. Interpret the assessment as a transition position, not a verdict.
2. Translate technical and organizational evidence into opportunity maps.
3. Identify value layers that are blocked by the current model.
4. Design sustainability paths that preserve ethical commitments.
5. Produce founder-facing recommendations in an invitational tone.

## Core documents

- `methodology.md` - full method and phase logic.
- `workflow.md` - step-by-step AI-agent workflow.
- `rules.md` - ethics, tone, evidence, and writing rules.
- `case_patterns.md` - distilled lessons from Flowsta and YourOwnAI.
- `templates/` - reusable document templates.
- `p2p-business-model-consulting/` - portable Cursor-style skill package.

## Communication stance

The consulting posture is:

```text
not a moral grade
not P2P ideology
not an accusation
not a sales pitch

an evidence-grounded opportunity map
```

The goal is to show where an organization stands now, which opportunities become visible from its own values and capabilities, and which transition path can increase prosperity without sacrificing its ethical center.
