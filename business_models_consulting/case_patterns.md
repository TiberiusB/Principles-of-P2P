# Case Patterns

This file distills reusable patterns from Flowsta and YourOwnAI. Use it as a memory aid, not as evidence for new cases.

## Shared pattern

Both cases followed the same consulting arc:

```text
technical autonomy
-> company-led hybrid
-> missing peer governance / benefit redistribution
-> larger ecosystem utility opportunity
-> staged path from service revenue to shared infrastructure
```

The point was not to criticize the organizations for having revenue models. The point was to show that their larger opportunities require economic and governance forms that match their technical and ethical claims.

## Flowsta pattern

### Current position

Flowsta is a user-owned identity, signing, recovery, and verification stack with Holochain components, open repositories, and a company-controlled dashboard/billing/coordination membrane.

### Decisive tension

Strong technical P2P substrate; weaker public evidence for peer governance, contribution accounting, and benefit redistribution.

### Consulting move

Reframe Flowsta from identity/signing service to shared trust infrastructure for hApps, Moss-like groupware, Nondominium groups, Unyt agreements, open ventures, and OVNs.

### Technical-to-economic map

- Vault and local keys enable identity continuity and consent memory.
- Sign It enables provenance, authorship, rights, contribution receipts, and governance attestations.
- Holochain DNAs and agent linking enable cross-hApp identity and verification.
- CAL export and backup enable portability and credible exit.
- Community nodes and public verification enable shared infrastructure.

### Sustainability insight

Move the center of gravity from paid access to infrastructure contribution:

- service cash flow remains legitimate;
- ecosystem services monetize expertise;
- benefit redistribution rewards Flowsta when ventures generate value;
- long-tail non-revenue use creates diffusion and legitimacy.

## YourOwnAI pattern

### Current position

YourOwnAI is a local-first open-source AI tool with signed records, optional online model routing, user-held memory, and a strong sovereignty narrative.

### Decisive tension

Strong user sovereignty at the product layer; lighter evidence for organizational peer governance, contribution economics, and ecosystem stewardship.

### Consulting move

Reframe YourOwnAI from individual AI assistant to OurOwnAI: a group intelligence and socio-economic memory utility for teams, open ventures, and networks.

### Technical-to-economic map

- Local inference and local records enable user sovereignty.
- Signed sessions and receipts enable verifiable cognitive work.
- Project memory and exports enable group continuity.
- Flowsta/Vault adjacent architecture enables identity, provenance, and trust.
- hApp integration potential enables shared group workflows.

### Sustainability insight

Move from a conventional AI app revenue frame to an ecosystem utility frame:

- paid online relay and support remain legitimate;
- add-ons and modules can become edge ventures;
- group memory and contribution receipts can feed contribution accounting;
- nondominium object framing can protect core infrastructure from capture.

## Reusable consulting questions

Use these questions for future cases:

1. What does the organization already make technically possible?
2. What value layers are latent but not yet economically expressed?
3. Where does current monetization sit: service, gate, toll, infrastructure contribution, or benefit return?
4. What parts should remain company service?
5. What parts should become shared utility?
6. Which contributors are invisible under the current model?
7. What non-currency benefits matter?
8. What is the smallest edge venture that can test the new model?
9. What would make adoption feel like resilience rather than dependency?
10. What human judgment is needed before offering the advice?

## Common migration pattern

```text
current hybrid
-> legible boundary between service and utility
-> ecosystem integration package
-> socio-economic use-case pilots
-> shared utility core
-> steward circle
-> OVN-compatible edge ventures
-> field finance without enclosure
```
