# P2P Business Model Consulting

## Quick start

Use this skill to turn a Principles-of-P2P assessment into practical consulting.

1. Read the existing case-study files or create them using the repository assessment workflow.
2. Read `reference.md`.
3. Maintain evidence discipline: separate facts, gaps, interpretations, and suggestions.
4. Diagnose the current model before proposing alternatives.
5. Link technical capabilities to economic opportunities.
6. Use founder-friendly language: opportunity map, not verdict.
7. Validate claims with the human assessor before finalizing.

## Required stance

- Do not accuse the organization of extraction unless evidence requires it.
- Do not preach P2P or OVN doctrine.
- Treat current monetization as legitimate unless evidence says otherwise.
- Show how better economic opportunities can preserve the organization's ethical center.
- Explain OVN/P2P terms in plain language and cite grounded sources.

## Outputs

Use the templates in `../templates/` to produce:

- current model diagnosis;
- technical capability map;
- new value-layer opportunity map;
- sustainability model;
- migration path;
- founder-facing suggestions;
- human supervision log;
- claims checklist.
