# Collaborative Entrepreneurship: OVN x Enterprise Stack

## Short summary of "The Enterprise Stack" (Indy Johar)

The essay argues that entrepreneurship must move beyond a narrow product/service lens and be understood as **value-field formation**.  
It proposes nine enterprise layers: **Product, Service, Outcome, Value Chain, Value Tree, Platform, Ecosystem, Cascading Market, Mission Cascade**.  
Its core claim is that as enterprise moves into deeper shared consequences, governance and capital must also evolve (from startup finance to field finance), because systemic work requires market-shaping, coordination, legitimacy, and long-term capability building.

## OVN framing for collaborative entrepreneurship

This document integrates:
- The OVN model (`What is an open value network?`, `Economic model`)

### OVN design assumptions used throughout

- **Open participation** (permissionless where possible)
- **Transparency / holoptism** (shared visibility of process and value flows)
- **Commons + nondominium + plural property regimes**
- **Contribution accounting and fair benefit redistribution**
- **Peer governance and self-organization (stigmergy)**
- **Hybrid transitions** (operating in present markets while growing post-extractive alternatives)

## Working guidance for improving the spreadsheet

For each pattern row, add four new columns:
- `Enterprise Stack level(s)` (choose one or more of P/S/O/VC/VT/PL/E/CM/MC)
- `OVN fit` (high / medium / low)
- `P2P risk` (capture risk, lock-in risk, mission drift risk, governance complexity)
- `Adaptation rule` (how to implement the pattern without violating openness, transparency, and fair benefit redistribution)
